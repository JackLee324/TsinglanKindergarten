### 修复前：每次构建都出现的 E404 噪音 ###
npm error code E404
npm error 404 Not Found - GET https://registry.npmjs.org/generate-api-routes - Not found
npm error 404 'generate-api-routes@*' is not in this registry.
npm error 404 Not Found - GET https://registry.npmjs.org/generate-page-routes - Not found
npm error 404 'generate-page-routes@*' is not in this registry.

原因: scripts/build.sh 第 3 步无条件执行
  npx generate-api-routes  --server-dir ./server --out-dir ./dist &
  npx generate-page-routes --app-path ./client/src/app.tsx --out-dir ./dist &
这两个包是**妙搭平台内部工具**，公开 npm registry 上不存在。
妙搭上工具在 PATH 里所以正常；Docker/VPS/Zeabur 上必然 404，
而 404 的每一行都以 ERROR 级别进日志 —— 构建其实成功了，但日志像失败。
